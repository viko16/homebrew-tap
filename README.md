# viko16 的 Homebrew Tap

这两个应用支持 Apple Silicon Mac，系统要求为 macOS 14 或更高版本。

| 应用 | 安装命令 |
| --- | --- |
| [Agent WebKit](https://github.com/viko16/agent-webkit)（含 `awb` 命令） | `brew install --cask viko16/tap/agent-webkit` |
| [Whistle Menubar](https://github.com/viko16/whistle-menubar)（需先配置本机 Whistle） | `brew install --cask viko16/tap/whistle-menubar` |

更新已安装的应用可运行 `brew update`，再运行 `brew upgrade --cask <应用名>`。卸载使用 `brew uninstall --cask <应用名>`。
